# Сумеречный лес: выбранное оформление

Четыре PNG получены встроенным image_gen. Точные запросы — prompts.json,
хеши и области атласов — SOURCES.json. props/ground используют солнечные PNG
только как опоры планировки; scout/guard созданы заново. Исходники скопированы
без изменения пикселей и alpha. Солнечные опоры сохранены в Git (ed7f161), из активного проекта удалены.

- props.png: дом с оберегом/фонарём, хвойное дерево, брёвна, забор, ящик, камни.
- ground.png: два материала — приглушённая трава и серо-коричневый грунт.
- scout.png / guard.png: по 3 ракурса × 4 фазы; боковой вид зеркалится.
  Взрослые пропорции, серый капюшон игрока и бурая куртка/каска охранника.

tools/build_dusk_art.py читает alpha и создаёт только AtlasTexture/SpriteFrames
в resources/art/forest_dusk. PNG и сцены он не перезаписывает. Регионы определены
по фактическим промежуткам, а не идеальной сетке генератора; margin выравнивает
ступни. Масштаб в сценах даёт высоту до 64 px. После замены PNG проверить регионы,
масштаб, опору ступней, движение и силуэты попадания в движке.

scenes/forest_dusk/ содержит самостоятельные сцены окружения. Персонажи/ящик —
scenes/player.tscn, enemy.tscn, loot_container.tscn; старых промежуточных сцен нет.
Физика/оружие/AI/лут остаются общими. Размеры спрайтов окружения согласованы
с прежними видимыми габаритами; изменение рисунка не меняет коллизии.
lighting.tscn содержит OvercastLight и слабый тёплый свет у фонаря дома.
Это пасмурный поздний день с хорошей видимостью; ночной режим ещё не создан.
Общая атмосфера и местный свет регулируются в Inspector отдельно от PNG.

Набор экспериментальный: четыре направления, оружие пока отдельная простая
геометрия; полноценная анимация смерти и отдельная лесная озвучка ещё впереди.
