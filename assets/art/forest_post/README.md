# Пиксельный лесной пост

Первый игровой набор по выбранному владельцем концепту №3. Не утверждённая
графика полной игры. Четыре PNG созданы встроенным image_gen; точные запросы —
*_prompt.txt: [объекты](props_prompt.txt), [персонаж](scout_prompt.txt),
[охранник](guard_prompt.txt), [земля](ground_prompt.txt).
SOURCES.json содержит SHA-256 и используемые области атласов.
Референс — собственный сгенерированный концепт из
artifacts/concepts/style_2026_10_22/03_pixel_checkpoint.png.

- props.png: дом, сосна, брёвна, секция забора, ящик и камни.
- scout.png / guard.png: по 3 ракурса × 4 позы. Боковой зеркалируется.
- ground.png: два покрытия, трава и грунт; повторяются локальным шейдером.

PNG скопированы без изменения байтов/альфы. Нормализация кадров — через
AtlasTexture region/margin в resources/art/forest_post; мягкие края генерации
отсекаются cutout.gdshader при рендеринге. Для пересборки ресурсов:
Python + Pillow, tools/build_forest_art.py. Он не редактирует изображения.
Масштаб спрайта/позиция основания задаются сценой, физический размер — отдельно.

Файлы концепта не загружаются игрой. Никаких готовых ассетов ZERO Sievert,
Tarkov или других игр в набор не импортировано. Это первый проверяемый
набор: равномерность пикселей, анимации и читаемость оцениваются в живой игре.
