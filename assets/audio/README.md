# Временные звуки прототипа

Оригинальные синтезированные эффекты, созданные для этого проекта.
Сторонние записи и звуки других игр не использовались.
Исходные WAV — моно, PCM 16 bit, 44.1 kHz; воспроизводятся штатными средствами Godot.
В `.wav.import` явно задано `compress/mode=0`: для этих коротких эффектов
используется несжатый PCM, соответствующие sidecar-файлы сохраняются в Git.

| Файл | Событие |
| --- | --- |
| player_shot.wav | Более короткий и резкий выстрел игрока |
| guard_shot.wav | Более низкий выстрел охранника |
| dry_fire.wav | Сухой щелчок пустого магазина |
| reload_start.wav | Извлечение магазина |
| reload_finish.wav | Установка магазина / затвор |
| guard_ready.wav | Короткий сигнал начала подготовки очереди |
| player_hit.wav | Глухая реакция на урон игроку |
| active_reload_success.wav | Короткое мягкое созвучие только при попадании в тайминг |

Эти тембры нужны для проверки обратной связи, финальный саунд-дизайн ещё не выбран.
Потоки и уровни оружия меняются на `Aim/Weapon/Audio` в Inspector;
общая громкость и mute — на шине **SFX** в панели Audio редактора.
Награда активной перезарядки длится 0.19 с; отдельный канал TimingSuccess
с уровнем −12 dB (выстрел игрока −6 dB) не обрывает механический звук.
Исходный пик награды 0.32, выстрела 0.68; фактический пик награды в микшере ниже.
Промах не воспроизводит отдельного эффекта, награда не повторяется при завершении.
Слушатель следует за игроком; звуки охранника затухают с расстоянием и панорамируются.
Акустика стен и реверберация пока не моделируются.

Воспроизводимый исходник — `tools/generate_audio.gd`. Скрипт работает только
при явном запуске и защищает существующие файлы от случайного перезаписывания.
Для намеренного пересоздания временного набора ему передают `-- --overwrite`.
Не запускать перегенерацию поверх заменённых вручную финальных звуков.
Для генерации только одного нового эффекта без изменения остальных:
`-- --only=active_reload_success`. Защита от перезаписывания сохраняется.
`artifacts/audio_preview.wav` — прежний обзор первых семи звуков таблицы;
`artifacts/audio_preview_active_reload_success.wav` — отдельный обзор награды
до применения игровой громкости. Полная перегенерация создаёт обзор всего набора.
