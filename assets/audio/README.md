# Звук и микшер

## Настройки игрока

На базе — кнопка «Настройки» или Esc. В рейде — Esc → «Настройки» → «Звук».
Экран общий для базы и паузы; вкладка «Экран» содержит прежние настройки окна.
Ползунки 0–100% применяются сразу; 0% действительно отключает категорию.
Временно включена калибровка: 50% — прежний базовый микс без изменения громкости.
Ниже 50% — ослабление (25% = половина амплитуды), выше — усиление в децибелах:
категории до +12 dB при 100%, общая громкость до +6 dB. Оба усиления складываются.
Средняя отметка выделена риской; точное усиление видно в подсказке процента.
«Исходный микс · 50%» возвращает все ползунки к нейтральному уровню.
После ручного подбора владельцем выбранные значения нужно отдельно принять как
новый базовый микс и вернуть ползунки к 100% с ослаблением вниз. Автоматического
утверждения/переноса подобранного микса сейчас нет.
«Слушать» воспроизводит короткий пример категории даже в паузе; нет примера
у пока пустых категорий. Пример не расходует патроны и не влияет на AI.
Назад, Esc, другая вкладка или F2 останавливают пример.

AudioSettings — Autoload; пользовательские проценты — в user://audio.cfg.
Снимок выбранных владельцем значений для звукового коммита —
resources/audio/calibration_reference.cfg. Это справочная копия: игра её не
загружает, она не назначает стандарт и не заменяет пользовательский audio.cfg.

Формат пользовательского audio.cfg:
meta/version = 2, секция volume со стабильными ID. Версия 1 переносится без
изменения усиления: старый процент делится на 2, включая общую громкость и mute.
Перенесённый профиль записывается атомарно в v2; повторная загрузка v2 не делит
значения ещё раз. Сохранённые калибровочные проценты выше 50 также сохраняются. Файл независим от progress.json
и display.cfg, переживает смену сцен и перезапуск. Запись после 0.35 с без изменений,
при выходе из настроек и при завершении игры: временный файл, flush, rename.
Ошибки записи показаны в меню; неизвестная версия защищена от перезаписи.
EXTRACTION_TEST_AUDIO=1 отключает автоматическое чтение/запись предпочтений;
тесты диска явно выбирают другие файлы в изолированном AppData.

## Категории и будущие назначения

| ID / шина | Назначение |
| --- | --- |
| master / Mix | Общая громкость всех категорий перед окончательным ограничителем |
| player_weapons / PlayerWeapons | Всё оружие игрока: выстрелы, перезарядка, пустой спуск, активный тайминг; будущие типы оружия |
| enemy_weapons / EnemyWeapons | Оружие NPC, изготовка, перезарядка; будущие фракции и боссы |
| footsteps / Footsteps | Шаги всех актёров, будущие поверхности, бег и экипировка при движении |
| interactions / Interactions | Контейнеры, лут тел, поиск, перенос/выброс/подбор вещей, лечение; будущие двери, крафт, ремонт |
| impacts / Impacts | Материалы попаданий, физическое получение урона, разрушения |
| ambience / Ambience | Постоянный фон, ветер, погода, лампы и механизмы окружения |
| interface / Interface | Будущие меню/уведомления, акценты редкого лута, начало/результат рейда и сигналы эвакуации |
| voices / Voices | Будущие реплики персонажей, речь и рация |
| music / Music | Будущая музыка меню/локаций; короткий мотив результата относится к Interface |

Окончательная Master содержит HardLimiter с потолком −1 dB; её фейдер остаётся
0 dB и не управляется ползунками. Ползунок общей громкости управляет Mix → Master,
поэтому усиление проходит через ограничитель, включая одновременное усиление групп.
Служебная SFX (+2 dB) объединяет эффекты → Mix; Ambience/Music идут прямо в Mix.
Проценты меняют фейдеры категорий, а громкость конкретной записи задаёт SoundCue
или компонент. На 50% фейдер каждой категории и Mix равен 0 dB. Сильное усиление
может сжимать динамику через лимитер: отсутствие клиппинга не доказывает качество
на слух. Подобранный профиль должен пройти игру, включая наложение звуков.
PlayerGunfire и компенсация −6 dB удалены. Чтобы сохранить прежний выстрел игрока,
его Cue теперь −8 dB вместо −2 dB; целиком WeaponAudio игрока — PlayerWeapons.
Выстрел охранника уменьшен ещё на 3 dB: Cue 0 dB. ReadyAudio −2 dB до EnemyWeapons.
Ручное SFX mute по-прежнему отключает все эффекты; общий ползунок включает и фон.

Взаимодействия сближены по 100-мс энергии реального сигнала, с учётом вариантов,
а не одной нормализацией пиков: усилены тихие поиск, подбор, перенос и фазы лечения.
Открытие/закрытие остаются немного выразительнее. Это первичный баланс,
субъективная громкость требует игры. Не выравнивать выстрел, шаг и лечение между
разными категориями до одной громкости. Новые записи подключены отдельной группой;
игровые тайминги и калибровочные предпочтения не менялись.

## Текущие записи

Первая группа банка владельца ElevenLabs: 31 WAV mono PCM16 48 kHz — 12 оружия,
12 боя, 7 шагов. Вторая группа — 19 WAV взаимодействий/лечения для 10 действий;
Третья — 5 stereo WAV сигналов рейда; четвёртая — 4 WAV лампы (фон и три сбоя); всего 59 записей владельца. Исходники снаружи проекта не изменены. SOURCES.json каждой
категории содержит исходное имя/ранг/SHA-256, интервал, усиление и хеш результата;
CREDITS.md — происхождение. Это генерации владельца, не CC0/CC BY прежних пакетов.

Оружие: владелец полностью заменил выстрелы карабина тремя новыми записями
(основной, -2, -3), по 0.8065 с. В игре carbine_shot_01..03, веса 3/2/1 без
повтора подряд. Полные файлы, stereo average после проверки фазы, общий gain 0.8,
Cue −3 dB; без выравнивания к энергии прежних выстрелов. Старый запрет -3/-4
касался другого набора; новый -3 разрешён. Четыре выстрела винтовки прежние.
Shot имеет max_polyphony=4: следующая запись не обрывает хвост предыдущей.
Перезарядка различается по оружию, отмена не даёт ложного окончания.
Награда активного R — основной reload_timing, Cue −16 dB; промах не озвучивается.

Бой: бетон/дерево по одному варианту, металл четыре, реакция врага три,
игроку отдельная запись. Impacts имеет четыре мировых голоса с затуханием;
ActorDamageAudio даёт одну физическую реакцию на принятый damaged,
включая попадание при минимуме 1 HP в режиме бессмертия F2.
Лечение и тестовая установка HP не запускают её. Отдельного сигнала убийства нет.

Прежние шаги на техническом стенде: три бетонных и четыре металлических варианта; shuffle bag без повторов,
80 px/шаг, игрок −16 dB, охранник −12 dB, металл дополнительно −2 dB.

Взаимодействия/лечение заменены банком владельца: 19 WAV для 10 действий.
Основные — открытие/закрытие дерева, начало/конец лечения и подбор. С весами ранга
и без прямого повтора — поиск (2), раскрытие (3), перенос (4), падение (2), процесс
лечения (3). Подготовка: проверенное mono, PCM16 48 kHz, полная исходная длина,
исходная атака (кроме описанной ниже правки начала лечения), только 5 мс fade
в конце; скалярное усиление по максимуму RMS
100 мс, с пиком не выше 0.8. Cue gain 0 dB. Цели RMS до панорамы: дерево 0.075,
лечение/падение/подбор 0.060, раскрытие 0.050, поиск 0.045, UI-перенос 0.030.
В реальном микшере при нейтральных ползунках измерено около 0.022–0.038 RMS
за активные 100 мс: близкие действия, открытие/закрытие чуть выразительнее.
Это технический ориентир, не подтверждение одинаковой воспринимаемой громкости.
Прежние 16 аудиофайлов и их импорты/лицензии/метаданные удалены после проверки
ссылок (35 файлов); происхождение новых — interactions/SOURCES.json/CREDITS.md.

Поиск 4.48 с не начинается заново при каждой находке: продолжается под раскрытием,
пока остаются неизвестные вещи. Конец/закрытие гасят его. Новая фаза открытия/
закрытия заменяет прошлую Action. Лечение остаётся 3 с. По игровому тесту начало
сокращено с 2 до 0.5 с: выбран фрагмент 1.32–1.82 с, fade-in 5 мс / fade-out 12 мс;
без изменения высоты/скорости или громкости. По следующему игровому тесту
паузы между фазами и повторами удалены: начало/основной цикл перекрываются
на 0.14 с, повтор цикла тоже. После успешного применения финал входит
с перекрытием 0.24 с: процесс продолжает затихать под ним. Эти параметры
открыты в InteractionAudio; лечение по-прежнему 3 с, финал не предсказывается.
SoundPlayer.crossfade использует два голоса, sine/cosine по линейной амплитуде,
отменяет старый tween при переиспользовании голоса. Пауза замораживает огибающие,
отмена гасит оба голоса без финала. Внешний WAV-мастер не изменён, монтаж отражён в SOURCES.json.
Отмена во время начала/процесса, пауза, смена сцены и отсутствие дублей проверены.
События рейда и лампа подключены следующими отдельными поставками; внешний вид лампы и редкость треска одобрены владельцем.

Фон склада — выбранный владельцем ElevenLabs #3, warehouse_bed_loop.ogg,
stereo 48 kHz, 30 с, только преобразование формата. WAV-мастер в ambience/sources/
исключён из импорта. Bed −4 dB, появление 2.5 с, случайный старт.
industrial_lamp.tscn сохранён как компонент; сейчас Details/DepotLamp находится
только в tests/fixtures/system_yard.tscn. На фонарь лесного дома этот звук ещё
не перенесён. Локальный фон 9.88 с
(основной lamp_buzz, склейка 120 мс), три сбоя по 3 с (веса 3/2/1).
Сбои без повтора подряд, первый через 9–16 с, затем 18–38 с тишины после конца.
Фон/сбои mono PCM16 48 kHz, −3 dB, дальность 520/650 px; фон появляется 1.5 с.
Свет слегка нерегулярно снижается во время сбоя, без отключения/смены видимости.
Пауза замораживает звук/свет/расписание, stop включает остановку фона лампы.
Происхождение/хеши/склейка — ambience/SOURCES.json, поле lamp_bank.
Новые порывы/металл не подключены; пять рейдовых сигналов подключены ниже. Голоса и музыка
тоже не добавлены. ambient-dark-looped/rain-forest не использовать без задачи.

Промпты — AUDIO_PROMPTS.md; аудит банка — AUDIO_BANK_REVIEW.md; план — AUDIO_PLAN.md.
Пауза/смерть/затухание/панорама проверяются автоматикой. Слышимость и художественный

## Лесная озвучка и хранение

Новая группа в forest/: 31 mono PCM16 WAV 48 kHz и один stereo Vorbis-фон.
Итого игровой банк — 90 коротких WAV и два OGG; отдельно сохранён прежний WAV-мастер
складского фона в ambience/sources с .gdignore. Он не импортируется в игру.
Четыре профиля шагов: dirt (3 варианта), grass/wet_dirt/puddle (по 4). Основной
footstep_dirt и варианты -2/-3 и т. п. подготовлены без изменения высоты/скорости:
убрана лишняя тишина, проверено сложение stereo в mono, DC, короткие краевые fade,
скалярное усиление по RMS100 с потолком пика 0.88. Трава чуть мягче грунта.
Параметры/исходные имена/SHA256 — forest/SOURCES.json; исходники не менялись.

Рисуемые Polygon2D дорожек задают границы грунта; под ними трава. Вода выбирается
по alpha Sprite (включая flip), вокруг — влажная кайма. Области не блокируют физику.
Кусты (3 WAV) и высокая трава/папоротники (4 WAV) дают шорох только при движении:
не чаще 0.65 с и повтор через 60 px в том же растении, два голоса, шина Footsteps.
Неподвижность/телепорт не запускают шорох; пауза замораживает, смерть останавливает.

Основной forest_ambience.wav преобразован в stereo OGG с 120 мс стыком (29.88 с),
уровнем RMS 0.07 до плеера; фон −4 dB, появление 2.5 с, случайный старт.
Crow (2 WAV), Woodpecker (2), Wind (3), TreeCreak (2) — отдельные локальные AmbientSpot
на шине Ambience. Первый через 12–22 с, последующие через 25–45 с после конца,
без наложения деталей и повтора подряд одного источника/варианта. Скрип дерева
необязателен по художественной оценке владельца; не смешан с постоянной петлёй.
Второй вариант лесного фона не включён в проект. Музыка не добавлена.

Все нужные игре записи находятся внутри assets/audio; зависимости от внешних
assets/sounds и assets/sounds/new sounds нет. Абсолютные source_folder в старых
SOURCES.json — историческое происхождение, игра их не читает. Внешние библиотеки
можно убрать без нарушения запуска. Для будущего монтажа полезен отдельный архив
полных оригиналов/альтернатив: в игровом банке только выбранные подготовленные файлы.
tools/prepare_forest_audio.py принимает папку оригиналов явно, требует numpy/soundfile
только для повторной подготовки; Godot/Python при запуске игры её не вызывает.
Примеры «Слушать» для шагов/окружения используют новый грунт и лесной фон.
Пользовательская калибровка не сброшена. Сигнал/маршрутизация проверены, субъективный
баланс нового набора ещё требует игрового прослушивания владельцем.

## События рейда

Пять основных записей ElevenLabs в raid/: старт 2 с, успех/провал по 4 с,
пульс 1 с, отмена 1.2 с. Stereo PCM16 48 kHz без сжатия; полный звук, только
скалярный gain и 5 мс fade конца. SOURCES.json/CREDITS.md описывают происхождение.
Интерфейсные сигналы без пространственного затухания, шина Interface; пульс слышен
только при отсчёте выхода игрока. Период 1.0 → .4 с, без повышения pitch.
RaidAudio переживает переход на базу, не переигрывает сохранённые результаты.
Пауза останавливает расписание и голоса. Успех зависит от фактического сохранения.
Предпочтения громкости не менялись. Владелец одобрил лампу и редкость треска; уровни громкости ещё подбирает.
