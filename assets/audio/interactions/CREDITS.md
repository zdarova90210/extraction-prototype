# Звуки взаимодействий из банка владельца

Источник — ElevenLabs Sound Effects, генерации и отбор владельца проекта.
Эти записи не обозначаются как CC0/CC BY прежних заменённых пакетов.
Внешние исходники в C:/zdarova90210/game-projects/assets/sounds не изменялись.
Имена, SHA-256 исходника/результата, ранг, формат и обработка — SOURCES.json.

19 WAV для 10 действий: основные открытие/закрытие дерева, начало/конец лечения,
подбор; вариативные поиск (2), раскрытие (3), перенос (4), падение (2), лечение (3).
Сначала основной файл; веса вариантов убывают по рангу, прямого повтора нет.

Подготовка: проверенное mono-усреднение stereo, PCM16 48 kHz без сжатия,
полная длина/исходная атака, только 5 мс fade в конце. Одно скалярное усиление
на запись по максимальной энергии 100 мс, с потолком исходного пика 0.8.
Для непозиционного переноса целевой уровень ниже, чем у мировых источников;
это компенсирует панорамирование мирового звука, а не меняет пользовательский микс.
Компрессии, изменения pitch/скорости или игрового времени обработки нет.
Профили SoundCue оставляют уровень 0 dB для дальнейшей настройки.

Kenney/Sheyvan и их лицензии/метаданные удалены вместе с полностью заменёнными
файлами после проверки ссылок. Текущая маршрутизация, калибровка и будущие
назначения — assets/audio/README.md. Окончательный баланс проверяется в игре.
